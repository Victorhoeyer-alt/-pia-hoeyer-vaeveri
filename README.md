# Pia Høyer Væveri

Minimalistisk portfoliohjemmeside med Decap CMS.

## Redigering
Efter opsætning af GitHub OAuth i Netlify åbnes redigeringspanelet på `/admin/`. Her kan Pia:

- ændre tekster og links
- udskifte billeder
- ændre rækkefølgen
- tilføje og fjerne værker

## Udgivelse
Forbind dette repository til Netlify. Publish directory er projektets rod (`.`), og der er ingen build command.
